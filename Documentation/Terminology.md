- Course code: e.g. "MATH 1014"
- Course number: the number in the course code
- Department: e.g. "MATH" in "MATH 1014"
- Faculty: e.g. "LE" in "LE/EECS 3421"
- Course: The whole overall course, e.g. "MATH 1014"
- Section: Each section of the "Course", e.g. Section U
- Class/module: e.g. "LECT", "LAB", "TUTR"
- Class session: Each individual time that class happens, e.g. LECT on Monday 
                 from 12:00-14:00
